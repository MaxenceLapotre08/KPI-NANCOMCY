# Structure des Onglets Google Sheets

Ce fichier me permet de comprendre la structure exacte de vos feuilles de calcul.
Veuillez le remplir avec les informations de chaque onglet que vous souhaitez que j'analyse.

## Instructions

Pour chaque onglet, veuillez copier/coller le modèle ci-dessous et le remplir avec les informations suivantes :

1.  **Nom de l'onglet :** Le nom exact de l'onglet dans votre Google Sheet.
2.  **Ligne d'en-têtes :** Copiez-collez la ligne complète des en-têtes de colonnes (la ligne 3, d'après vos scripts). Utilisez des `|` pour séparer les noms de colonnes.
3.  **Colonnes avec Formules :** Listez les noms des colonnes qui contiennent des formules que vous avez écrites manuellement dans la feuille (par exemple, pour calculer le ROAS, le CPL, etc.). C'est crucial pour que je m'assure que le script ne les écrase jamais.
